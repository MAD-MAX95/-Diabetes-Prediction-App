# 🩺 Diabetes Prediction App

A Machine Learning-powered web application that predicts the likelihood of diabetes based on a user's medical information. The application is built using **Python**, **Scikit-learn**, and **Streamlit**, providing an intuitive interface for users to input health parameters and receive instant predictions.

## 🚀 Features

* Predicts diabetes risk using a trained Machine Learning model.
* Interactive and user-friendly Streamlit interface.
* Real-time predictions based on user input.
* Data preprocessing and feature scaling for improved model performance.
* Fast, lightweight, and easy to deploy.

## 🛠️ Tech Stack

* **Python**
* **Pandas**
* **NumPy**
* **Scikit-learn**
* **Streamlit**
* **Joblib/Pickle** (for model serialization)

## 📊 Input Features

The model predicts diabetes using the following medical parameters:

* Pregnancies
* Glucose Level
* Blood Pressure
* Skin Thickness
* Insulin
* BMI (Body Mass Index)
* Diabetes Pedigree Function
* Age

## 🤖 Machine Learning Workflow

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Scaling
* Model Training
* Model Evaluation
* Model Serialization
* Streamlit Deployment

## 📈 Model Performance

The prediction model was trained and evaluated using appropriate machine learning techniques to achieve reliable classification performance. Metrics such as **Accuracy**, **Precision**, **Recall**, and **F1-Score** were considered during model evaluation.
